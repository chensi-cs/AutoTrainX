# 项目介绍
基于 Python 的自动化训练框架，支持在服务器远程执行机器学习脚本，自动检测运行时错误，并通过大模型生成修复代码，实现一键重训。

# 后端
一个“用大模型自动生成 + 修复机器学习训练代码，并在 AutoDL 远程服务器上自动部署、训练、纠错”的 FastAPI 后端
```
前端
 │
 │ 1. 上传数据集 + 选择算法
 ▼
FastAPI 后端
 │
 │ 2. 解析/修复数据集
 │ 3. 调 SiliconFlow LLM 生成 train.py（不运行）
 │
 ▼
前端展示代码
 │
 │ 4. 用户确认 → 上传到 AutoDL
 ▼
AutoDL 服务器
 │
 │ 5. 创建 .venv + pip install
 │ 6. 运行 train.py
 │
 │ 7. 如果报错：
 │    - 收集报错 + 代码 + 数据摘要
 │    - 再次调用 LLM 修复
 │    - 覆盖 train.py
 │    - （可选）自动重跑
 ▼
结果日志返回前端

```
